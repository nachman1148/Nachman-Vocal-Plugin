# Nachman Vocal Plugin

ממשק אונליין בעברית לעבודה עם וואקאל וזיהוי גובה צליל.

## הפעלה
פתח את `index.html` בדפדפן או פרסם דרך GitHub Pages.

## בגרסת אבטיפוס זו
- ממשק בעברית עם מונחים באנגלית
- טעינת קובץ אודיו והאזנה
- הפעלת מיקרופון וזיהוי תו בזמן אמת
- פקדי סולם, מהירות תיקון ועוצמת תיקון (ממשק בלבד)

## חשוב
מנוע תיקון גובה הצליל האוטומטי (Auto-Tune DSP) עדיין לא ממומש. הפקדים אינם משנים את הצליל בשלב זה. זו אינה עדיין גרסת VST או כלי תיקון מוכן להפקה.

## פרסום
GitHub → Settings → Pages → Deploy from a branch → Branch: main → Folder: / (root) → Save.
